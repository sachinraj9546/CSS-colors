# 🎨 CSS Colors Practice Project

A simple HTML & CSS project demonstrating different CSS selectors, color styling techniques, IDs, classes, nested selectors, and `nth-of-type()` usage.

Built as part of frontend practice to strengthen CSS fundamentals and selector targeting.

---

## 🚀 Live Concepts Covered

- Element Selectors
- Class Selectors
- ID Selectors
- Combined Selectors
- Nested Selectors
- `nth-of-type()` Selector
- Link Styling
- Typography Styling
- Background Colors

Because apparently humans decided memorizing selector specificity was a healthy educational experience.
