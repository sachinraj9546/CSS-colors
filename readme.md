CSS Colors Practice Project

A tiny HTML + CSS practice project demonstrating different CSS selectors, colors, pseudo-selectors, IDs, classes, and element styling. Humanity really looked at plain text and decided, “What if the text was orange-background chaos with selectively aggressive blue headings?” And thus CSS was born.

Project Overview

This project showcases:

Element selectors
Class selectors
ID selectors
Combined selectors
nth-of-type() usage
Styling links without inline CSS
Background colors and typography styling

Files used:

index.html
style.css

project-folder/
│

Features
HTML Structure

The HTML file contains:

Multiple heading tags (h1, h2, h4)
Paragraphs with and without IDs/classes
Styled links
Ordered list items with selective coloring
CSS Styling

The CSS demonstrates:

Global body styling
Underlined article heading
Class-based heading styles
ID-specific overrides
Paragraph customization
Nested selector targeting
nth-of-type() selectors
Link background styling
List item color targeting
How to Run
Download or clone the project
Keep both files in the same folder
Open index.html in any browser

That’s it. No frameworks. No build tools. No 47MB node_modules folder pretending to be “lightweight”.
